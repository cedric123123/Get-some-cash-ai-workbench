# 搞钱事务所-AI电商运营工作台 V1.0.1

## 中文

本次更新完善 CSV 导入体验，并新增官方店铺 API 接入基础。

- CSV 支持带引号的逗号、换行和 BOM；修复价格、库存、平台识别问题，新增预览、逐行校验和确认导入。
- 修复竞品搜索恢复、导入内容转义和异常 URL 请求处理。
- 新增「店铺接口」页面，支持店铺登记、服务端配置状态、手动同步、分页查询及店铺数据隔离。
- 店铺资料与同步缓存支持本地持久化；同步失败保留上次成功数据，重启后可识别中断任务。
- 实现淘宝／天猫只读连接器，覆盖店铺身份、在售商品及最近 7 天创建的默认类型订单。
- 新增接口配置文档，20 项自动化测试通过。

当前范围：淘宝连接器仍需获批应用、有效店铺授权及真实联调；拼多多和京东连接器尚未实现。原演示区任务和 CSV 数据仍在页面内存中，不随本次更新获得持久化。未实现自动改价、发货或发布。本服务面向本机单用户使用。

下载 ZIP 并解压，安装 Node.js 18+ 后运行 `npm start`，访问 http://127.0.0.1:4173/。Windows 用户也可双击 `启动工作台.cmd`。接口配置见 `docs/api-setup.md`。

欢迎使用、体验和测评！请通过 Issues 分享实际运营流程、导入体验、接口接入需求与可复现的问题。反馈中请勿包含店铺密钥、Token 或买家个人信息。

## English

Gaoqian Office — AI E-commerce Operations Workbench V1.0.1 improves CSV imports and introduces the foundation for official store API integrations.

- Robust quoted CSV parsing, numeric/platform validation, row errors and confirmation before import.
- Fixes for competitor search recovery, HTML escaping and malformed request handling.
- A dedicated store API page with registration, server configuration status, manual sync, pagination and store isolation.
- Persistent store metadata and snapshots, previous-cache retention after failures and interrupted-job recovery.
- A Taobao/Tmall read-only connector for shop identity, on-sale products and default order types created within the last seven days.
- Setup documentation and 20 passing automated tests.

The Taobao connector requires an approved application, valid merchant authorization and live validation. Pinduoduo and JD connectors are not implemented yet. Original demo tasks and CSV data remain in memory. No marketplace write operations are implemented. This service is intended for local single-user use.

Extract the ZIP, install Node.js 18+, run `npm start`, then open http://127.0.0.1:4173/. Windows users can also launch `启动工作台.cmd`.

Welcome to try and evaluate the release! Share reproducible issues and practical workflow feedback without credentials or customer personal data.
