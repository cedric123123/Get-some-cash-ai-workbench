# 官方平台 API 接入计划

核验日期：2026-09-11。状态：后端基础和淘宝只读连接器已实现，尚未进行真实店铺联调。当前实现与配置见 [开发版使用说明](api-setup.md)。

## 数据来源约定

按用户要求，后续真实店铺资料、商品、SKU、库存、订单等平台数据以各平台官方 API 为来源。工作台后端负责调用并缓存同步结果，前端通过工作台自己的接口读取数据。CSV 保留为迁移、补录入口，并标注来源；演示数据与真实店铺数据分开。

本地任务、内容草稿、审批记录属于工作台自身数据，需要本地持久化。平台 API 接入不能代替这部分保存能力。

### 淘宝 / 天猫

已找到以下官方查询文档；文档存在不代表当前应用已获调用权限：

| 能力 | 接口 | 官方文档 |
| --- | --- | --- |
| 卖家店铺资料 | taobao.shop.seller.get | [卖家店铺基础信息查询](https://developer.alibaba.com/docs/api.htm?apiId=42908) |
| 在售商品列表 | taobao.items.onsale.get | [出售中的商品列表](https://developer.alibaba.com/docs/api.htm?apiId=18) |
| 按创建时间查询交易 | taobao.trades.sold.get | [卖家已卖出的交易](https://developer.alibaba.com/docs/api.htm?apiId=46&source=search) |
| 订单详情 | taobao.trade.fullinfo.get | [单笔交易详细信息](https://developer.alibaba.com/docs/api.htm?apiId=54) |

商品列表文档说明仅返回部分信息，商品详情需另行查询；交易列表文档说明存在时间范围和订单类型限制，不能把一次列表返回当作全量历史订单。

授权与签名参见[官方授权说明](https://developer.alibaba.com/docs/doc.htm?articleId=120&docType=1)。库存、增量同步、售后、费用和推广指标的具体接口，接入前按当前应用类型和权限继续核验。

## 拟实现的工作台后端契约

以下是本项目后端契约；当前列表、登记、同步和分页查询已实现，日期/状态筛选与增量同步待补齐。这些不是平台官方接口：

| 工作台接口 | 作用 |
| --- | --- |
| GET /api/stores | 返回已授权店铺身份与连接状态 |
| GET /api/stores/:id/products | 读取该店铺已同步商品与 SKU |
| GET /api/stores/:id/inventory | 读取库存快照与更新时间 |
| GET /api/stores/:id/orders | 按日期、状态分页查询本地同步订单 |
| GET /api/stores/:id/sync-status | 展示最后成功时间、错误与权限缺失 |
| POST /api/stores/:id/sync | 触发读取平台数据的同步任务 |

每条平台记录保留 platform、storeId、sourceId、source、syncedAt；分页游标和增量检查点按店铺保存。接口失败保留上次成功数据并显示过期状态；没有数据时显示待同步，不能回退成演示数字。

## 实施顺序

1. 完成本地持久化与店铺隔离，再建立后端连接器边界。
2. 配置开发者应用、回调地址及服务端凭证存储，完成商家授权。
3. 优先接通拼多多店铺身份和商品/订单读取，再适配淘宝与京东。
4. 增加分页、增量同步、去重、失败重试和同步状态；限频以各接口文档及响应为准。
5. 经营指标只从已获得的数据计算；广告消耗、访客、转化等额外来源未接入时显示未接入。

密钥和访问令牌只由服务端保管，不放进前端、仓库或发布包。联调还需要各平台已开通的应用权限与店铺授权；不在聊天中索要明文密钥。

本次确定的是店铺数据读取路线，不包含自动改价、发货、商品发布，也不假定商家授权能读取其他店铺的竞品数据。
